## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
The difference between a file and a folder is that a file is is one single piece of information (i.e. word document, picture, excel file) but a folder consists of several files and can even hold other folders (i.e. it houses the files and can also be referred to as a container).Folders and files create a hierarchy forming a tree because the folders and files branch off one another. 
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
Window-style file paths and Linux-style file paths have a few key differences. Below is a list of key differences:
Windows                                              Linux
Uses lettered drives; most times 'C'                 Uses forward slash for its root
Uses back slashes                                    Uses forward slashes
Not case-sensitive                                   Case-sensitive 
Hides files with a toggle option                     Hides files instantly by using a period mark

```
